# Buzz team backup: Sietch Tabr

A backup of the Sietch Tabr agent team in Buzz:

- `sietch-tabr.team-instructions.md`: the team's instructions, exactly as Buzz holds them.
- `agents/<name>.agent.json`: one Buzz agent snapshot (`buzz-agent-snapshot` v1) per member, in the shape Buzz's agent export writes: name, instructions, runtime, model and provider. No keys, credentials, env vars or memory.
- `avatars/<name>.png`: each member's avatar. Agent snapshots only keep `https://` avatar links, and relay media links need relay sign-in and last only as long as the relay keeps the file, so the images are kept here.

This directory sits outside `src/`, so it is not packaged into the `ai-agent-rules` wheel and `ai-rules install` never deploys it.

Restoring creates **new** agents with **new** keys. The old identities are not reused, so channel memberships have to be redone.

## Restore

1. In Buzz, open Agents → Import an agent → Import snapshot, once for each file in `agents/`.
2. Set each agent's avatar from `avatars/` and its effort from the table above. Turn on **Remembers you** for Paul.
3. Create a team (New team) named Sietch Tabr, paste `sietch-tabr.team-instructions.md` as its instructions, and add the six agents.
4. Re-add the new agents to their channels.

## Refresh

1. In Buzz, open each agent's menu → Share → Export JSON, and overwrite its file in `agents/`. Remove the Remembers you section from Paul's instructions.
2. Copy the team's instructions into `sietch-tabr.team-instructions.md`.
3. Update the table if a type, model, provider or effort changed, and `avatars/` if an avatar changed.
