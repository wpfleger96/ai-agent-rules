# Target: Paper

A paper, research report, or long technical document, including reports produced by the `research` skill. For the guesses to count, run Frame before the user reads the document closely.

## Frame prompts

From the title and abstract only, the user writes what they expect the main claim, method, and weakest point to be. Question ideas if they are stuck:

- What is the main claim, and how big is the effect?
- What design or method supports it?
- What is the most likely confound or limitation?
- Would the result change what you do?

## Artifacts (Step 2)

1. The claims, each with its supporting evidence and effect size where reported.
2. The method: design, sample, measures, comparison.
3. Weaknesses: confounds, sample limits, generalizability, replication status.
4. How it relates to prior work the user knows.
5. What it changes in practice, if anything.

Cite page or section numbers for each claim.

## Review-question targets

The main claim and its strength, why the method does or does not support it, the key limitation, and the practical implication. Not author names or exact statistics unless the user needs them.
